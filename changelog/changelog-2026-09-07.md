# Documentation updates - September 7, 2026

September 7, 2026

Summary of documentation changes made on September 7, 2026.

## User Guides

-   **[Route Leak Prevention](/docs/user-guides/routing-and-networking-protocols/unicast/bgp/route-leak-prevention)**: New article explaining BGP roles from RFC 9234, role negotiation, and route leak prevention and detection, with configuration examples for provider/customer, route server, peering, and iBGP sessions. The BGP `local.role` and session `remote.role` entries in the CLI Reference now link to it.
