Summary of documentation changes made on July 21, 2026.

## Getting Started

- **[CHR and x86 Licensing](/docs/getting-started/routeros-licensing/chr/chr-licensing)**: Documented account binding, trial expiration, and license transfer behavior for CHR and x86 licenses.

## Hardware

- **[Disks](/docs/hardware/disks)**: Documented SED and FSTRIM limitations on USB-attached drives, clarified swap-over-container behavior, corrected the disk trim description, and added the swap max size limit.
- **[RouterBOARD](/docs/hardware/routerboard)**: Cross-referenced the new minimum-firmware and minimum-version fields shown by resource print.

## Diagnostics & Monitoring

- **[Resource](/docs/diagnostics-monitoring-and-troubleshooting/resource)**: Documented the minimum-firmware and minimum-version fields shown by resource print.

## Storage

- **[Self-Encrypting Drives](/docs/storage/self-encrypting-drives)**: Noted an FSTRIM limitation when an SED is used behind a USB bridge.
- **[RAID](/docs/storage/raid)**: Documented the /disk raid-scrub-cancel command.

## Containers

- **[Container Apps](/docs/containers/apps)**: Documented how to select the web port used by a container app.
