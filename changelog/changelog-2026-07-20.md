Summary of documentation changes made on July 20, 2026.

## Site

- **Documentation versioning**: The current documentation was frozen as version **7.24**, which is now selectable from the version dropdown. Frozen versions are excluded from search engine indexing, and site search no longer returns duplicate hits from frozen versions for pages that still exist in the current documentation.

## Authentication & AAA

- **[Certificates](/docs/authentication-authorization-accounting/certificates)**: Every certificate property across the documentation now links back to the certificate store. Affected pages include [RADIUS](/docs/authentication-authorization-accounting/radius), [User Manager](/docs/authentication-authorization-accounting/user-manager), [Container apps](/docs/containers/apps), [LoRa](/docs/internet-of-things/lora/general-properties), [MQTT](/docs/internet-of-things/mqtt), [Wiliot](/docs/internet-of-things/wiliot), [TR-069](/docs/management-tools/tr-069), [OpenFlow](/docs/network-management/openflow), [Fetch](/docs/system-information-and-utilities/fetch), [IPsec](/docs/virtual-private-networks/ipsec), [OpenVPN](/docs/virtual-private-networks/openvpn), and [SSTP](/docs/virtual-private-networks/sstp).

## Wireless

- **[WiFi](/docs/wireless/wifi)**: Clarified the Network section — a /interface/wifi/network entry without labels applies to all interfaces, and the examples are now annotated as network and radio presets. The MLO example gained a security.passphrase value.
