Summary of documentation changes made on September 17, 2026.

## Management Tools

- **[WinBox](/docs/management-tools/winbox)**: The page is no longer marked as work in progress. It now walks through the login screen (supported address formats, custom ports, RoMON, saving devices), the saved, neighbor and RoMON device lists, and the configuration interface (toolbar, sidebar, work area, resources), with annotated screenshots and a table for each part. Keyboard shortcuts are listed separately for Linux/Windows and macOS.

## Site

- Added a **Widen**/**Narrow** button to the top navigation bar. It switches the page content to the full window width and remembers your choice on every page.
