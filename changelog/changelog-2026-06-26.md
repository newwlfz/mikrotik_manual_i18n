Summary of documentation changes made on June 26, 2026.

## Mobile Networking

- **[LTE/5G Interface](/docs/7.24/mobile-networking/lte-5g)**: Added the show-capabilities command documentation, which displays modem features such as supported bands, RAT modes, APN limits, and passthrough support.
- **[LTE/5G Interface](/docs/7.24/mobile-networking/lte-5g)**: Clarified that the network-mode parameter requires both lte and 5g to be selected for 5G NSA; selecting 5g alone only connects to 5G SA.
- **[LTE/5G Interface](/docs/7.24/mobile-networking/lte-5g)**: Rewrote the monitoring section with updated /interface/lte/monitor output example showing cell-level data and modem metadata.
