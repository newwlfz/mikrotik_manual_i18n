# Documentation updates - October 12, 2026

October 12, 2026

Summary of documentation changes made on October 12, 2026.

## Internet of Things[​](#internet-of-things "Direct link to Internet of Things")

-   **[TG-LR Setup](/docs/7.24/internet-of-things/lora/user-guides/tg-lr-setup-guide)**: Formatting and reference pass. The note that a new device is in SHUTDOWN mode links to the magnet switch commands, command names are formatted as code, and the references to the LoRaWAN specification, the IEEE EUI standard and the known issues are now links. The supported regions table explains that the X-Y code is the region part of the 9-X-Y magnet switch sequence, its second column is the region code, and WW2G4 moved to the end with a note that it is enabled by default as the secondary band.
