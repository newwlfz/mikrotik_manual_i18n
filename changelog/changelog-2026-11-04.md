# Documentation updates - November 4, 2026

November 4, 2026

Summary of documentation changes made on November 4, 2026.

## Wireless

-   **[Configuring EasyMesh](/docs/wireless/wifi/configuring-easymesh)**: The introduction now states what the feature supports: CLI only (no GUI), `wifi-qcom` and `wifi-qcom-ac` only, WPS onboarding needs a `wpa2-psk` or mixed `wpa2-psk,wpa3-psk` fronthaul (no WPA3-only SAE), and DPP onboarding is not implemented. It also explains how the controller distributes fronthaul and backhaul settings and keeps one Layer 2 network.

## Hardware

-   **[ROSE Data Server](/hardware/rose-data-server)**: Reworked the product page with the product description (storage, 100G networking and container platform in a 20-slot U.2 chassis, ROSE edition) and the standard safety warnings.
