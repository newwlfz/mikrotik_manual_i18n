Summary of documentation changes made on June 4, 2026.

## Bridging & Switching

- **[Switch Chip Features](/docs/bridging-and-switching/switch-chip-features)**: Replaced external wiki.mikrotik.com links with internal documentation references for the Switch-Router configuration guide and the Master-port section.

## Getting Started

- **[Netinstall](/docs/getting-started/installation-and-upgrade/netinstall)**: Page rewritten and moved to the Installation and Upgrade directory. Updated with platform-specific tabs for Windows and Linux Netinstall workflow, new screenshots, and a description of the Netinstall package available from RouterOS 7.24beta1.
- **[IPv6 Neighbor Discovery](/docs/getting-started/networking-fundamentals/ipv6-neighbor-discovery)**: Added documentation for the advertise-dns=self option, which allows the router to advertise its own link-local IPv6 address as a DNS server via Router Advertisements.

## Hardware

- **[Peripherals](/docs/hardware/peripherals)**: Removed stale wiki.mikrotik.com Quectel modem compatibility links and replaced them with a clean modem reference table.

## Mobile Networking

- **[LTE/5G](/docs/mobile-networking/lte-5g)**: Fixed the broken RouterOS upgrade guide link in the offline FOTA firmware upgrade warning section.
