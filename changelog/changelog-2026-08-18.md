# Documentation updates - August 18, 2026

August 18, 2026

Summary of documentation changes made on August 18, 2026.

## Network Management

-   **[OpenFlow](/docs/network-management/openflow)**: Moved CLI parameters into the CLI Reference, and auto-filled previously missing parameter descriptions from the OpenFlow specification.

## Management Tools

-   **[SSH](/docs/management-tools/ssh)**: Changed the default host key type from RSA to Ed25519.

## CLI Reference

-   **[CLI Reference](/docs/cli-reference)**: Regenerated roughly 380 command pages to show only the accepted numeric ranges in parameter types, instead of full internal type expressions.
