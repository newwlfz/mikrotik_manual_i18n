Summary of documentation changes made on August 18, 2026.

## Network Management

- **[OpenFlow](/docs/7.24/network-management/openflow)**: Moved CLI parameters into the CLI Reference, and auto-filled previously missing parameter descriptions from the OpenFlow specification.

## Management Tools

- **[SSH](/docs/7.24/management-tools/ssh)**: Changed the default host key type from RSA to Ed25519.

## CLI Reference

- **[CLI Reference](/docs/7.24/cli-reference)**: Regenerated roughly 380 command pages to show only the accepted numeric ranges in parameter types, instead of full internal type expressions.
