Summary of documentation changes made on September 1, 2026.

## System

- **[Clock](/docs/7.24/system-information-and-utilities/clock)**, **[Device Mode](/docs/7.24/system-information-and-utilities/device-mode)**, **[E-mail](/docs/7.24/system-information-and-utilities/e-mail)**, **[Fetch](/docs/7.24/system-information-and-utilities/fetch)**, **[Files](/docs/7.24/system-information-and-utilities/files)**, **[Identity](/docs/7.24/system-information-and-utilities/identity)**, **[IP Packing](/docs/7.24/system-information-and-utilities/ip-packing)**, and **[Neighbor Discovery](/docs/7.24/system-information-and-utilities/neighbor-discovery)**: Fixed grammar and moved CLI parameter descriptions into the CLI Reference.
- **Interface Lists**: Removed the old System page and moved its content into the [CLI Reference](/docs/7.24/cli-reference/interface/list), updating all cross-links across the manual.

## Management Tools

- **[TR-069](/docs/7.24/management-tools/tr-069)**: Fixed grammar and styling and moved CLI parameters into the CLI Reference.

## Getting Started

- **[Upgrade](/docs/7.24/getting-started/installation-and-upgrade/upgrade)**: Documented secure package download and the IP version used for updates.
- **[x86 Licensing](/docs/7.24/getting-started/routeros-licensing/x86)**: Noted that the demo license is limited to a single interface.

## Containers

- **[Container Apps](/docs/7.24/containers/apps)**: Expanded the app YAML reference with new fields (auto-update, icon, url-path, user, entrypoint, healthcheck, secrets, configs, shm_size, stop_grace_period) and clarified the ports syntax.
