# Documentation updates - September 1, 2026

September 1, 2026

Summary of documentation changes made on September 1, 2026.

## System

-   **[Clock](/docs/system-information-and-utilities/clock)**, **[Device Mode](/docs/system-information-and-utilities/device-mode)**, **[E-mail](/docs/system-information-and-utilities/e-mail)**, **[Fetch](/docs/system-information-and-utilities/fetch)**, **[Files](/docs/system-information-and-utilities/files)**, **[Identity](/docs/system-information-and-utilities/identity)**, **[IP Packing](/docs/system-information-and-utilities/ip-packing)**, and **[Neighbor Discovery](/docs/system-information-and-utilities/neighbor-discovery)**: Fixed grammar and moved CLI parameter descriptions into the CLI Reference.
-   **Interface Lists**: Removed the old System page and moved its content into the [CLI Reference](/docs/cli-reference/interface/list), updating all cross-links across the manual.

## Management Tools

-   **[TR-069](/docs/management-tools/tr-069)**: Fixed grammar and styling and moved CLI parameters into the CLI Reference.

## Getting Started

-   **[Upgrade](/docs/getting-started/installation-and-upgrade/upgrade)**: Documented secure package download and the IP version used for updates.
-   **[x86 Licensing](/docs/getting-started/routeros-licensing/x86)**: Noted that the demo license is limited to a single interface.

## Containers

-   **[Container Apps](/docs/containers/apps)**: Expanded the app YAML reference with new fields (auto-update, icon, url-path, user, entrypoint, healthcheck, secrets, configs, shm\_size, stop\_grace\_period) and clarified the ports syntax.
