# 2026-11-04 · Session 01 — foundation and official-site recon

**Status:** repository, archive, Docusaurus scaffold and route spike are in
place. Content import has not started.

## What the user wants

- A source-faithful mirror of `https://manual.mikrotik.com/`.
- Phase 1: RouterOS **7.24 only**, plus Hardware Guides, Product news, Docs
  Changes, and a CLI comparison of 7.24 against itself.
- Docusaurus must use the same standard mechanisms as the official site: no
  invented routes, no bespoke replacement for versioning or plugin separation.
- Playwright must compare local builds against the live official pages.
- No translation, no language switcher, and no GitHub Actions in phase 1.
- New code and GitHub data live in a dedicated repository directory. The old
  `mikrotik-docs-i18n/` and `mikrotik_manual_i18n/` directories are invisible.
- Conversation history must be archived with a summary index for later
  sessions.
- The future multilingual layout must cover RouterOS, Hardware, CLI compare,
  Product news, and Docs Changes for every locale.
- Official CSS/JS and static assets should be reused wherever technically safe.
- The synchroniser must support later incremental updates.

## What was verified (read-only)

- Official generator: **Docusaurus 3.10.1**.
- RouterOS docs are versioned: 7.26 current, 7.25, 7.24.
- 7.24 contains **1,418** source documents, of which **1,054** are CLI
  Reference pages.
- Hardware is a **separate docs plugin instance** (`plugin-id-hardware`,
  `docs-version-current`) with **250** pages under `/hardware/`.
- Product news is a blog plugin at `/blog/` with **10** posts.
- Docs Changes is a second blog plugin at `/changelog/` with **132** posts.
- CLI comparison is an MDX page with `<CliCompare />` at
  `/docs/cli-reference/compare-versions/`, present only in the 7.26 docs.
  The 7.24 equivalent returns 404 upstream.
- `.md` endpoints work for RouterOS docs, including CLI pages. Hardware, Blog,
  and Changelog do not expose `.md`; they must be rendered with Playwright and
  converted with Turndown.
- The official 7.24 URLs are absent from `sitemap.xml`; the sitemap cannot be
  the inventory source for that version.
- Official CLI pages use `<ArgTable>` / `<ArgTableRow>` MDX components.

## Decisions

- New repository: `mikrotik-manual-mirror/` inside the current workspace.
- Git initialised locally on `main`; no remote.
- Docusaurus app lives at the repository root; pipeline code is under
  `pipeline/`; generated data under `data/`; screenshots and audits under
  `reports/`; resumable scratch under git-ignored `work/`.
- English content stays in the canonical Docusaurus directories. Future
  translations go into `i18n/<locale>/...` using the standard Docusaurus i18n
  plugin folders. CLI data is per-locale under `data/cli/7.24/`.
- Official compiled `main.js` / `runtime~main.js` are not injected, because
  they embed the official route and content manifest. The same Docusaurus
  version regenerates equivalent runtime code. Official static assets and
  separable CSS are reused; official bundles are snapshotted under
  `vendor/official/3.10.1/` for comparison.
- The comparison page will live under the 7.24 docs route unless the user
  explicitly asks for the literal current-version URL.
- Session archives contain visible messages and a full tool audit, but not
  hidden reasoning.
