## Overview

RouterOS licensing is based on two identifiers: **Software ID** and **System ID**. These identifiers determine how licenses are assigned and managed across different platforms.

- **Software ID** is used for MikroTik products (RouterBOARD) and x86 systems.
- **System ID** is used for Cloud Hosted Router (CHR).

Because licensing behavior differs depending on the platform, separate guides are provided for each case.
