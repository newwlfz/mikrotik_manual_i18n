## tool/sniffer/stop 
**Type:** Command

Stops the sniffer. The captured packets stay in memory for 10 minutes, or until the next [`start`](/docs/7.25/cli-reference/tool/sniffer/start): list them in [`packet`](/docs/7.25/cli-reference/tool/sniffer/packet), [`protocol`](/docs/7.25/cli-reference/tool/sniffer/protocol), [`host`](/docs/7.25/cli-reference/tool/sniffer/host) and [`connection`](/docs/7.25/cli-reference/tool/sniffer/connection), or write them to a file with [`save`](/docs/7.25/cli-reference/tool/sniffer/save).
