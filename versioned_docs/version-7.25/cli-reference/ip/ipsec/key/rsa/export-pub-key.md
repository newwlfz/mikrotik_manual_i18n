## ip/ipsec/key/rsa/export-pub-key 
**Type:** Command

Export public key to file from one of the existing private keys.

<ArgTable c1="Argument" c2="Type" c3="Description">
<ArgTableRow arg="key" typ="enum">Name of the RSA key to export.</ArgTableRow>
<ArgTableRow arg="file-name" typ="string">Name of the file to export the public key to.</ArgTableRow>
</ArgTable>
