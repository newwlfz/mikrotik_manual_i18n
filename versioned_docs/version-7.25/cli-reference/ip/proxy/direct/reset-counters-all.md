## ip/proxy/direct/reset-counters-all 
**Type:** Command

Resets the `hits` counter of all rules in [`/ip/proxy/direct`](/docs/7.25/cli-reference/ip/proxy/direct). For an overview, see [Web Proxy](/docs/7.25/network-management/proxy/web-proxy).
