## ip/proxy/direct/reset-counters 
**Type:** Command

Resets the `hits` counter of the given rules in [`/ip/proxy/direct`](/docs/7.25/cli-reference/ip/proxy/direct), for example `/ip/proxy/direct/reset-counters [find comment=test]`. For an overview, see [Web Proxy](/docs/7.25/network-management/proxy/web-proxy).
