## file/copy 
**Type:** Command

Copies a file or directory. Directories are copied recursively, with all their contents. See the [Files](/docs/7.25/system-information-and-utilities/files#copy-a-file-or-directory) guide.

<ArgTable c1="Argument" c2="Type" c3="Description">
<ArgTableRow arg="name" typ="file">Destination name of the copy. Can include a path, to copy into a different directory.</ArgTableRow>
</ArgTable>
