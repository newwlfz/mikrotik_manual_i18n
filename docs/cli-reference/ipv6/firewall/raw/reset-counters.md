## ipv6/firewall/raw/reset-counters 
**Type:** Command

Sets the packet and byte counters of the selected rules of this table back to zero. See [Common Firewall Matchers and Actions](/docs/firewall-and-quality-of-service/firewall/common-firewall-matchers-and-actions).
