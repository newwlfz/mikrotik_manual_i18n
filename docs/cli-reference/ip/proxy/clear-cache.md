## ip/proxy/clear-cache 
**Type:** Command

Deletes all objects from the cache of the web proxy. Changing any setting in [`/ip/proxy`](/docs/cli-reference/ip/proxy/) also clears the cache. For an overview of caching, see [Web Proxy](/docs/network-management/proxy/web-proxy).
