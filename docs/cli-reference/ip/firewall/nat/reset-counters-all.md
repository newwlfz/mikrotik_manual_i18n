## ip/firewall/nat/reset-counters-all 
**Type:** Command

Sets the packet and byte counters of all rules of this table back to zero. The counters of the other firewall tables do not change. See [Common Firewall Matchers and Actions](/docs/firewall-and-quality-of-service/firewall/common-firewall-matchers-and-actions).
