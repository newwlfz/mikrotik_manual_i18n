## system/resource/hardware/authorize 
**Conditions:** !powerpc, !smips
**Type:** Command
Allow or forbid the use of a USB hardware device (used when authorization is turned on in `usb-settings`).

<ArgTable c1="Argument" c2="Type" c3="Description">
<ArgTableRow arg="allow" typ="bool">Authorize the USB device (`yes`) or keep it unusable (`no`)</ArgTableRow>
</ArgTable>
