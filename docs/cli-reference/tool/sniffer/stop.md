## tool/sniffer/stop 
**Type:** Command

Stops the sniffer. The captured packets stay in memory for 10 minutes, or until the next [`start`](/docs/cli-reference/tool/sniffer/start): list them in [`packet`](/docs/cli-reference/tool/sniffer/packet), [`protocol`](/docs/cli-reference/tool/sniffer/protocol), [`host`](/docs/cli-reference/tool/sniffer/host) and [`connection`](/docs/cli-reference/tool/sniffer/connection), or write them to a file with [`save`](/docs/cli-reference/tool/sniffer/save).
