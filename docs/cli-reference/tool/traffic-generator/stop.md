## tool/traffic-generator/stop 
**Type:** Command
Stops the background traffic generator started with the [start](/docs/cli-reference/tool/traffic-generator/start) command. The collected statistics remain available under the [stats menu](/docs/diagnostics-monitoring-and-troubleshooting/traffic-generator#stats) (`/tool/traffic-generator/stats/*`).
