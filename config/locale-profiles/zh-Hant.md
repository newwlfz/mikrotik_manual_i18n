# 繁體中文（臺灣正體）

- script: Hant
- register: 技術文件體，簡潔、直接、第二人稱；操作步驟用祈使句，說明用陳述句；避免簡體直譯與大陸用語
- punctuation: 全角標點（，。：；！？（）「」），數字、英文與中文之間保留半角空格；不得混用簡體標點
- keep-verbatim: 程式碼、指令、選單路徑、參數名、列舉值、檔案路徑、錨點、URL、產品名（RouterOS、MikroTik、WinBox、WebFig、CAPsMAN）
- preferred terms: interface→介面；queue→佇列；routing table→路由表；packet→封包；firewall→防火牆；bridge→橋接；user→使用者；default→預設；log→日誌；firmware→韌體；client→用戶端；port→埠；software→軟體；network→網路；information→資訊；setting→設定；server→伺服器；database→資料庫；switch→交換器；file→檔案；document→文件；video→影片；print→列印；support→支援；and→與
- examples:
  - bad: 请点击“设置”按钮来配置接口，默认情况下用户可以使用服务器的数据包队列。
    good: 請在「設定」中配置介面；預設情況下，使用者可以使用伺服器的封包佇列。
  - bad: 这个软件支持网络信息查询。
    good: 此軟體支援網路資訊查詢。
  - bad: 打印视频文件的配置。
    good: 列印影片檔案的設定。
